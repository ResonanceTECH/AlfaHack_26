# Демо-документы для кабинета предпринимателя

Фейковые PDF для ручной проверки загрузки в UI. Данные вымышленные (ИП Петров Иван Сергеевич, ИНН `770123456703`). Не для официального использования!!!!

## Куда загружать (основной сценарий)

Все **6 файлов** из этой папки рассчитаны на блок **«Документы по заявке»** на карточке кредитной заявки.

| Шаг | Действие |
|-----|----------|
| 1 | Войти как предприниматель |
| 2 | **Заявки** → открыть активную заявку (или создать новую) |
| 3 | URL: `/app/applications/<id>` |
| 4 | Секция **Документы по заявке** |
| 5 | В каждый слот — **Загрузить** / drag&drop / **Заменить** |

Форматы, которые принимает UI заявки: PDF, JPEG, PNG, XML.

---

## Соответствие файла слоту

| Файл | Слот в UI | Обязательность | Что внутри (кратко) |
|------|-----------|----------------|---------------------|
| `выписка_40702_окт2026.pdf` | Выписка по расчётному счёту | обязательный | Выписка по р/с за ~6 мес., PDF/XML-стиль, обороты демо-ИП |
| `passport_petrov.pdf` | Паспорт ИП / руководителя | обязательный | Стилизованный скан разворота + регистрация |
| `kp_equipment_2026.pdf` | Договор / КП на оборудование | обязательный | Коммерческое предложение на оборудование (обоснование цели) |
| `usn_2025.pdf` | Налоговая декларация / УСН | обязательный | Демо-форма УСН за 2025 (не точная копия бланка ФНС) |
| `consent_bki.pdf` | Согласие на запрос БКИ | обязательный | Согласие на запрос кредитной истории |
| `collateral_equipment.pdf` | Залог / обеспечение (если есть) | опционально | Опись/акт залогового оборудования |

В демо-сиде слоты часто уже частично заполнены (выписка, паспорт — «Загружен», УСН — «На проверке», КП и БКИ — «Нужен», залог — «Опционально»). Любой слот можно **заменить** своим файлом из этой папки.

## Подробно по файлам

### 1. `выписка_40702_окт2026.pdf`

- **Слот:** Выписка по расчётному счёту  
- **Hint в UI:** PDF / XML, 6–12 месяцев  
- **Смысл:** подтверждение оборотов по р/с для скоринга и финпрофиля заявки  
- **Куда ещё можно:** отдельно выписку для анализа денег — `/app/statements/upload` (финпрофиль / «Загрузить выписку»). Это **другой** поток, не чек-лист заявки. Для проверки слота заявки грузи именно сюда: `/app/applications/<id>`.

### 2. `passport_petrov.pdf`

- **Слот:** Паспорт ИП / руководителя  
- **Hint:** скан разворота + регистрация  
- **Смысл:** идентификация заёмщика / руководителя  
- **Дубль в vault:** похожий документ в хранилище компании — «Паспорт владельца» (`/app/documents`), но для заявки нужен именно слот на карточке заявки.

### 3. `kp_equipment_2026.pdf`

- **Слот:** Договор / КП на оборудование  
- **Hint:** обоснование цели — PDF  
- **Смысл:** подтверждение цели кредита (equipment) — КП/договор поставки  
- Типичен для инвестиционного/целевого сценария; в UI заявки слот всегда в чек-листе демо.

### 4. `usn_2025.pdf`

- **Слот:** Налоговая декларация / УСН  
- **Hint:** последний отчётный период  
- **Смысл:** налоговая отчётность за период (демо-УСН 2025).

### 5. `consent_bki.pdf`

- **Слот:** Согласие на запрос БКИ  
- **Hint:** подписанный скан или демо-галочка  
- **Смысл:** согласие на запрос в бюро кредитных историй.  
- В карточке компании есть UI «Согласие на запрос БКИ» в блоке проверок — это не замена файла в слоте заявки.

### 6. `collateral_equipment.pdf`

- **Слот:** Залог / обеспечение (если есть)  
- **Обязательность:** нет  
- **Смысл:** документы на залог (опись оборудования и т.п.). Можно не грузить — заявка по чек-листу всё равно «едет» по 5 обязательным.

## Связь с продуктовыми требованиями бэкенда

На бэкенде обязательный набор зависит от **кредитного продукта**, например:

- оборотный: паспорт, ЕГРИП, выписка 6 мес., карточка счёта 51  
- линия: паспорт, ЕГРИП/ЕГРЮЛ, выписка 12 мес., договоры с поставщиками  
- инвестиционный: паспорт, бизнес-план, КП, документы на залог  
- овердрафт: паспорт, выписка 3 мес.

Для ручного демо загрузки достаточно слотов на `/app/applications/<id>`.
